# Roadmap

All phases 1–5 are implemented. Phase 6 is partially in place.

## Phase 1 — Core refactor ✓
- TypeScript strict mode, shared types, modular project structure

## Phase 2 — Task model ✓
- Task schema, validation, persistence, metadata, filtering/grouping

## Phase 3 — Scheduling engine ✓
- Scoring engine, heuristics, conflict resolution, workload balancing, fragmentation reduction

## Phase 4 — Auto rescheduler ✓
- Skip handling, adaptive rescheduling, overload reduction, task splitting, momentum preservation

## Phase 5 — Behavioral layer ✓
- Completion pattern tracking, preferred execution windows, procrastination detection, adaptive recommendations

## Phase 6 — AI assistance (in progress)
- Conversational task input
- Schedule explanations
- Predictive planning
- Adaptive suggestions
